# ✦ Алхимия — Alchemy Game

Однопользовательская игра на C# WinForms в стиле Little Alchemy.  
**75 элементов · 92 рецепта · 8 категорий · Звуковые эффекты**

## Быстрый старт

**Требования:** Windows 10/11, [.NET 6 SDK](https://dotnet.microsoft.com/download/dotnet/6.0), Visual Studio 2022

```bash
git clone https://github.com/<НИК>/AlchemyGame.git
cd AlchemyGame
dotnet run
```

Или: открыть `AlchemyGame.csproj` → **F5**

## Как играть

1. Нажми на элемент в **инвентаре** (снизу) — он появится на поле
2. **Перетащи** один элемент на другой
3. Если рецепт существует — оба исчезают, появляется новый элемент
4. Новые элементы помечаются **NEW!** и добавляются в инвентарь
5. Цель: открыть все **75 элементов**!

## Архитектура проекта

```
AlchemyGame/
│
├── Program.cs                  # Точка входа — запуск MainForm
├── AlchemyGame.csproj          # Настройки проекта (.NET 6 WinForms)
├── app.manifest                # DPI-настройки для Windows
│
├── Models/
│   ├── Element.cs              # Данные одного элемента (Id, Name, Emoji, Color)
│   ├── Recipe.cs               # Рецепт: InputA + InputB → Result
│   └── WorkspaceElement.cs     # Экземпляр элемента на рабочей области (позиция)
│
├── Data/
│   └── ElementData.cs          # ВСЕ элементы (75) и рецепты (92) — база данных игры
│
├── Services/
│   ├── CraftService.cs         # Поиск рецепта по двум Id
│   ├── Game.cs                 # Игровое состояние: инвентарь, поле, крафт
│   └── SoundService.cs         # Генерация и воспроизведение звуков (без .wav файлов!)
│
└── UI/
    ├── MainForm.cs             # Главное окно: шапка, toast, компоновка
    ├── WorkspacePanel.cs       # Рабочая область: карточки, пересечения, крафт
    ├── InventoryPanel.cs       # Нижняя панель с кнопками открытых элементов
    └── ElementControl.cs       # Перетаскиваемая карточка одного элемента
```
